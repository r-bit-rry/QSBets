# Project Brief: QSBets

## Core Purpose
QSBets is an event-driven stock analysis and investment recommendation system that combines technical analysis, fundamental data, and AI-powered insights to generate high-quality trading recommendations.

## Key Goals
1. Generate accurate and actionable stock trading recommendations
2. Provide comprehensive analysis incorporating multiple data sources:
   - Technical indicators (RSI, MACD, BBands)
   - News and social media sentiment
   - SEC filings (10Q/10K reports)
   - Macroeconomic factors
3. Validate recommendations through backtesting
4. Deliver insights via Telegram notifications and web dashboard

## Core Requirements
1. Event-driven architecture for scalable analysis
2. Multi-source data collection and aggregation
3. AI-powered analysis using configurable LLM backends
4. Technical analysis with clear interpretation
5. Real-time notifications for high-quality recommendations
6. Interactive dashboard for result visualization
7. Automated backtesting capabilities

## Success Criteria
1. High-quality recommendations (threshold-based filtering)
2. Positive backtesting results
3. Comprehensive analysis reports in YAML format
4. Reliable event processing and notification delivery
5. Accurate technical indicator interpretations
6. Effective noise filtering in sentiment analysis

## Project Scope
### In Scope
- Stock data collection and analysis
- Technical indicator calculation and interpretation
- News and social media sentiment analysis
- SEC filing analysis
- AI-powered recommendation generation
- Backtesting system
- Telegram notifications
- Web dashboard
- Event-driven processing system

### Out of Scope
- Automated trading execution
- Portfolio management
- Risk management tools
- Real-time market data streaming
- Complex order types/strategies

## Timeline
Active development project with regular updates and improvements tracked through the tasks system.

## Stakeholders
- Developers
- Users receiving trading recommendations
